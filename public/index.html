用于把团队外部成交订单批量导入当前项目。导入时会按当前项目的订单字段设置、业务员账号、代理商库、企业重复和展位状态做校验。

未选择文件
导入前请确认
1. `sales_name` 必须和系统里的业务员账号名称完全一致。
2. 必填字段会按当前项目的“订单字段设置”检查，不完整的行不会导入。
3. 如果要导入代理商订单，`agent_name` 必须已经存在于代理商库。
4. 展位已占用时必须明确填写 `is_joint=是` 才会按联合参展处理，否则视为疑似填错展位号。
5. 外发收集表拿回后，请删除填写说明行，只保留真实订单数据再上传预检查。
6. 单次最多导入 300 行，建议先分批预检查。
常用字段说明
`is_agent` 支持 `直招` / `代理商招展` / `0` / `1`。
`no_code_checked`、`no_booth_order` 支持 `0` / `1` / `是` / `否`。
`is_joint` 支持 `0` / `1` / `是` / `否`，只在确认为联合参展时填写 `是`。
`fees_json` 需要是 JSON 数组，例如 `[{""name"":""广告费"",""amount"":2000}]`。
`selected_booths_json` 适合多展位订单，数组元素可带 `booth_id`、`area`、`unit_price`、`standard_fee`、`is_joint`。
`status` 仅支持 `正常`、`已退订`、`已作废`。
`created_at` 推荐格式 `YYYY-MM-DD HH:mm:ss`。
本功能不导入已收金额；收款请后续通过 ERP 同步或手工收款处理。
