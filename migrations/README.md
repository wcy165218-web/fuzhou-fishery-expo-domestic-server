# D1 迁移说明

这个目录只存放 D1 数据库的正式增量迁移 SQL。

以后只要涉及线上/正式环境要执行的表结构、索引、字段补充、生产补数据，都按下面规则处理：

1. 我先在这里新增一个 SQL 文件。
2. 文件名使用 `YYYYMMDD-HHMM-变更说明.sql`。
3. 我会在回复里告诉你去 Cloudflare D1 控制台执行，还是用 Wrangler 执行。
4. 没有对应 SQL 文件的数据库改动，不算正式变更。

注意：

- 本地重置/初始化脚本放在 `db/local/`
- SQL 模板放在 `db/templates/`
- 不要把 `DROP TABLE` 型本地脚本或模板文件再放回 `migrations/`

建议约定：

- 一个需求对应一个 SQL 文件。
- 每个 SQL 文件顶部写清楚“用途、影响表、是否可回滚”。
- 生产库不要直接手点修改后就结束，必须把 SQL 留档到这里。
